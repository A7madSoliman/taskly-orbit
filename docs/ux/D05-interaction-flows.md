## Shared interaction rules

| Pattern | Requirement and boundary |
|---|---|
| Validation and forms | Validate only evidenced fields and rules locally; associate labels/errors and retain the active draft when appropriate. Local validity does not replace backend checks. Separate invalid input, rejection and uncertain result. Credentials are not transferred between forms or promised durable retention. |
| Explicit editing | Field Save/Cancel is explicit; no blur autosave. Epic PATCH accepts exactly one field; project edits may require a companion value; task OP-22 accepts a nonempty strict subset. Apply each journey's actual request and response rules. |
| Dirty drafts | Protect in-app close, navigation and project switching; keep editing is the safe default, discard affects local draft only. Browser Back, reload or tab close may not be interceptable or preserve drafts. |
| Pending and uncertainty | Prevent duplicate submissions and temporarily protect in-app dismissal; announce pending. If outcome is unavailable, release the lock and offer keep reviewing or explicit leave. A submitted write is not canceled by leaving. Preserve the active draft where safe; no automatic replay. Operation-specific read reconciliation may fail or be insufficient, and precedes any deliberate repeat where applicable. Treat errors as definite only where the evidence supports no write. |
| Task status | Confirmation-first: retain and label the last confirmed status while pending; use a validated OP-22 response to update the presentation. Offer keyboard/touch non-drag actions; no transition graph, retry safety, durability or conflict-free update is inferred. G-08/DEC-07 remain holds. |
| Permission and context | Read access is distinct from edit eligibility; show checking, readonly, denied or unavailable as supported, without inferring a role or cause. Recheck relevant scoped access and use neutral feedback where missing and denied are indistinguishable. OP-03 is an internal verifier, not a new browser profile API. |
| Loading and recovery | Distinguish successful empty/zero, no-match, loading and unavailable. Retain useful earlier results on partial/incremental failures where appropriate; offer scoped read retry. Do not manufacture values, totals or failure causes. Avoid stale results replacing a newer scope. |
| Nested surfaces and focus | Named topmost dialog/panel owns focus and Escape; suspend parent focus handling. Close nested task to its actual epic origin and trigger when present. Dirty confirmation takes top ownership. Restore trigger or stable fallback; focus and announce destination on navigation. |
| Origin and history | Preserve the actual origin, project, supported query/filter, range, scroll and trigger within the active interaction where available. In-app Back uses that origin or a labeled safe parent; direct task/epic entry uses same-project Tasks/Epics if available, otherwise Projects. Browser Back follows real history and may leave Orbit. Forward/overlay restoration is an unverified design intent. No reload, offline or cross-device restoration guarantee. |
| Authentication and deep links | Delegate restoration to J-03; validate session and scoped destination independently, reject unsafe return targets, avoid infinite refresh and do not infer expiry from a transport failure. General post-auth return is held by DEC-08; invitation and recovery remain separate. |
| Statistics and calendar | Global Statistics is conditional and does not inherit the current project filter. OP-27 accepts supported dates and optional project/status; OP-28 accepts dates only; OP-08 supplies project options. Sections load/retry independently. Metric semantics, filter effects and all-project access remain G-17 holds; no scheduling writes. |
| Bilingual, themes and motion | Desktop, tablet and mobile have deliberate layouts; English LTR/Arabic RTL, mixed-direction content, Arabic expansion, light/dark, keyboard/touch, visible focus and non-color feedback are required. Reduced motion keeps equivalent information with static changes. DEC-11 preference placement/default/retention and DEC-12 date/numeral conventions remain unresolved. No measured accessibility or contrast compliance is claimed. |
