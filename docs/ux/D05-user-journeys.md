## J-01 — Access an account

- **Goal and priority:** Access an account; P0.
- **Entry and preconditions:** Sign in or protected entry; Public; sign-up branch requires account details.
- **Feature IDs:** F-01. **Surfaces:** OR-S01, OR-S02, OR-S05. **Operations:** OP-01, OP-02.
- **Backend gaps / decisions:** G-01, G-13; DEC-08. All remain open; approval is bounded by D03-v1/D04-v1.
- **User decisions:** Choose sign in, signup or recovery; correct explicitly rejected input; choose a safe exit or an evidence hold after uncertainty.
- **Qualified success:** Signup acknowledgement is distinct from a session; only a confirmed login result reaches safe continuation, whose destination access remains independently checked.

If result becomes unavailable, release the navigation lock and allow the listed uncertainty exits; leaving never cancels a submitted write.
- **Responsive, RTL, theme and accessibility:** Desktop, tablet and mobile; tablet/mobile unified drawer; English LTR/Arabic RTL and both themes; keyboard/touch, associated errors, visible focus, announcements, contextual focus return and static reduced-motion equivalents. No runtime or compliance claim.
- **Open holds and later validation:** G-01, G-13, DEC-08; verify relevant branch with D-06 state matrix and D-07/D-21/D-22 prototypes, real-device and assistive-technology review. No assumed role/transition/date policy.
