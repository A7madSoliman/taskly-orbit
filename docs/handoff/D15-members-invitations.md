Sensitive invitation input is never displayed. A verified session and explicit Accept precede the write; authentication does not submit it. Safe post-sign-in continuation is conditional on available context and never reconstructs it. Pending prevents duplication and guards exit; an unavailable result releases the guard and does not trigger automatic replay. Definite rejection and restriction remain distinct from uncertainty. Expiry or conflict is named as a cause only when the response specifically supports it; no reason is inferred from status alone.

OP-13 200 acknowledges acceptance and can contain a validated project UUID or null; it does not independently establish membership, role or destination access. A supplied project reference permits an explicit continuation through normal context/access checks; absent a reference, use Projects when authenticated or a safe exit. Follow actual safe origin when available. Do not invent token refresh, invitation preview, acceptance-status read, role policy or automatic redirect.
